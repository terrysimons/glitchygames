Code Complexity Metrics#

How the most complex modules in glitchygames/ changed over the project's git history, measured by wily. The modules are the 15 with the highest total cyclomatic complexity (the sum over their functions and methods) at the published commit. Each graph has one line per module (click a module in the legend to hide or show it), with a point at each commit that changed the module's value.

The graphs are generated, not kept in git: nox -s docs-deploy generates them before it builds the published site. To see them in a local build (mkdocs serve), generate them first with uv run python scripts/generate_complexity_graphs.py (or nox -s code-complexity -- --graphs), which measures the committed history (HEAD) in a temporary worktree and writes them to docs/quality/graphs/; until then this page has only this text.

Generated at commit b7d5bd57 (2026-10-23) from all 280 commits.
