Joystick Demo: every connected joystick and game controller, live.

Run it with joystick-demo or python -m joystick_demo and plug devices in and out. Each device the engine sees (Scene.input_devices, glitchygames/input/input_devices.py) gets a column: its name, GUID, instance id and device index (the devices door's descriptor), the layer its events come from, then that layer's live axes, held buttons and hats. A mapped game pad shows its controller layer (CONTROLLER_AXIS_* / CONTROLLER_BUTTON_* ids, axes on pygame's int scale); any other device its joystick layer. The readout is drawn from the frame's input snapshot, so a replay of a recording shows exactly what the recorded run showed.

The header names the input mode (--input-mode: auto shows every device, joystick every device on its joystick layer, controller only mapped pads), the last device connected or disconnected, and the last input event and the handler it reached: each press arrives once, from the device's event layer.
