RPG Sprite Studio

bitmappy (loaded from the deployed play/ site) wired to the MasterHUB deck — load a sprite and it shows on the dial and the center key.

Instructions
  • Keys — top row picks the sprite, the 3×3 is the facing grid, the bottom row steps the palette color.
  • Knobs — R / G / B of the selected color.
  • Rollers — flip sprite pages.
  • Dial — the navigator: turn to move, press to activate; scrubs frames in the film strip.
  • Sliders — zoom, FPS, onion range / alpha / opacity.
  • Base LED — the selected paint color.
