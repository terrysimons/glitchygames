*[AI]: Artificial intelligence: here, the local AI service's language models

*[GPU]: Graphics processing unit

*[JSON]: JavaScript Object Notation
*[MIDI]: Musical Instrument Digital Interface
*[p50]: The 50th percentile (median): half the frames took longer
*[p95]: The 95th percentile: 5% of the frames took longer
*[p99]: The 99th percentile: 1% of the frames took longer
*[RGBA]: Red, green, blue and alpha (opacity)
*[RSS]: Resident set size: the memory a process holds
*[SBOM]: Software bill of materials: every package the project installs
